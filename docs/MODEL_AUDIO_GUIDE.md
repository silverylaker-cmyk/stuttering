# 모델 음성 녹음 가이드

연장발화 훈련기의 "🔊 모델 듣기"에 쓰이는 시범 음성입니다. 환자는 **모델 듣기 → 하이라이트 따라 하기 → 내 녹음과 비교** 순서로 훈련하므로, 모델 음성의 속도와 발화 패턴이 곧 환자가 따라 할 기준이 됩니다.

## 1. 무엇을 녹음하나

| 항목 | 내용 |
|---|---|
| 속도 단계 | 70 / 120 / 150 / 180 SPM (음절/분) |
| 문장 | 난이도 1·2·3 각각 **01–10번** (총 30문장, `content/sentences.json`) |
| 파일 수 | 4단계 × 30문장 = **120개** + Pull-out 시범 1개 |
| 순수 발화 시간 | 약 19분 (재녹음 포함 실제 작업 2–3시간 예상) |
| 체크리스트 | [`docs/model-audio-checklist.csv`](model-audio-checklist.csv) — 파일명·문장·**목표 길이(초)** |

목표 길이 = 음절 수 ÷ SPM × 60. 예: `L1-01` "아침에 물을 마셔요." (8음절)

| SPM | 70 | 120 | 150 | 180 |
|---|---|---|---|---|
| 목표 길이 | 6.9초 | 4.0초 | 3.2초 | 2.7초 |
| 음절당 | 0.86초 | 0.50초 | 0.40초 | 0.33초 |

## 2. 앱이 기대하는 발화 패턴

앱의 하이라이트는 **모든 음절을 같은 간격**으로 진행하고, 띄어쓰기·마침표에서 쉬지 않습니다. 모델 음성도 이 리듬과 맞아야 환자가 듣고 따라 할 때 혼란이 없습니다.

공통 원칙 (화면 큐와 동일)
- **부드러운 시작**: 첫소리 전에 숨을 살짝 내쉬며 작게 시작
- **가벼운 접촉**: ㅂ·ㄷ·ㄱ 같은 파열음도 입술·혀를 살짝만 닿게
- **이어 말하기**: 음절 사이·단어 사이를 끊지 않고 목소리를 계속 유지
- 문장 전체를 **한 호흡**에. 70 SPM 난이도 3(약 25–29음절, 22–25초)만 쉼표 자리에서 짧은 숨 1회 허용
- 글자 그대로 읽기 (음절 수가 길이 판정 기준)

단계별 느낌
| SPM | 특징 |
|---|---|
| 70 | 전형적 연장발화. 모음을 길게 늘이고 음절이 물 흐르듯 이어짐. 단조로워도 괜찮지만 과장된 억양은 피함 |
| 120 | 여전히 늘이지만 길이가 절반 정도. 부드러운 시작은 분명하게 |
| 150 | 천천히 말하는 보통 대화에 가까움. 이어 말하기 유지 |
| 180 | 거의 자연스러운 속도. 기법은 들릴 듯 말 듯, 자연도(NAT)가 좋게 들리도록 |

## 3. 속도 맞추는 방법 (권장: 앱 자체를 페이스메이커로)

1. **기기 A**(휴대폰·태블릿)에서 앱을 열고 훈련 › 연장발화 훈련기 › 모드를 **하이라이트+메트로놈**으로.
   - 원장 PIN으로 단계 목표 SPM을 70 → 120 → 150 → 180으로 바꿔 가며 녹음 (원장 설정 › 단계·목표 처방). 데모용 기기를 따로 쓰면 편합니다.
   - Phase 3 이상(목표 SPM 없음)으로 두면 설정 카드의 속도 슬라이더로 자유롭게 바꿀 수 있습니다.
2. 기기 A에 **이어폰**을 꽂아 메트로놈 소리가 녹음에 들어가지 않게 합니다.
3. **기기 B**(다른 휴대폰의 음성 메모, 또는 PC + USB 마이크 + Audacity)로 녹음합니다.
4. "▶ 따라 하기"를 누르고 하이라이트에 맞춰 읽습니다. 한 문장 끝나면 1–2초 쉬고 다음 문장.

## 4. 녹음 환경

- 조용한 방 (옷이 많은 드레스룸·커튼 있는 방이 울림이 적음), 냉장고·에어컨 끄기
- 마이크와 입 사이 **20–30cm**, 정면보다 살짝 비스듬히 (파열음 바람 소리 방지)
- 휴대폰은 비행기 모드 (알림음·전파 잡음 방지)
- 형식: WAV 또는 휴대폰 기본 음성 메모(m4a) 모두 가능, 44.1/48kHz
- **같은 화자·같은 장소·같은 마이크**로 120개를 모두 녹음 (중간에 바뀌면 이질감)
- 한 SPM 단계를 한 번에 몰아서 녹음하면 속도가 안정적입니다 (70 전부 → 120 전부 …)

## 5. 파일 정리

긴 테이크 하나로 녹음했다면 Audacity에서 문장마다 레이블(이름 = 문장 ID)을 붙이고 *파일 › 내보내기 › 여러 파일 내보내기 › 레이블 이름 사용*으로 자릅니다.

아래 구조로 모읍니다 (파일 이름 = 문장 ID, 대소문자 정확히):

```
raw/
  70/   L1-01.wav … L1-10.wav, L2-01.wav … L2-10.wav, L3-01.wav … L3-10.wav
  120/  (같은 30개)
  150/  (같은 30개)
  180/  (같은 30개)
  pullout.wav
```

## 6. 변환·검사 (자동)

```bash
# ffmpeg 필요: macOS  brew install ffmpeg   /  Windows  winget install ffmpeg
npm run audio:prepare -- raw
```

자동으로 처리하는 것
- 앞뒤 무음 제거 → 음량 정규화(-16 LUFS) → 앞뒤 0.3초 여백 → AAC 64kbps 모노 m4a
- `public/audio/model/{spm}/{id}.m4a` 에 저장
- **실제 길이를 목표 길이와 비교**해 ±15%를 넘으면 실제 SPM과 함께 경고 → 해당 문장만 다시 녹음
- 누락 파일 목록 출력

120개 기준 총 용량 약 10MB이며, 빌드 시 모두 오프라인 캐시에 포함됩니다.

## 7. Pull-out 시범 음성 (`pullout.wav`)

말더듬 수정법 › Pull-out 화면의 "🔊 시범 듣기"에 쓰입니다. 10–20초 분량 예시:

> "바— (첫소리에서 살짝 막힌 듯 멈춤, 1초) … (긴장을 풀며) 바아아다에 가요." → 1초 쉼 → "가— … 가아아방을 들어요."

막힘을 과장하지 말고, **막힘 → 긴장 이완 → 길게 늘이며 빠져나오기**의 대비가 들리게 합니다.
(Cancellation은 앱이 정지 타이머만 제공하므로 별도 음성이 필요 없습니다. 원하시면 영상으로 시범을 보여 주세요.)

## 8. 검수와 반영

1. 언어재활사가 120개를 듣고 속도·연장발화 패턴을 확인 → `content/REVIEW.md` 의 "모델 음성" 행에 날짜·검수자·결과 기록
2. `public/audio/model/` 을 커밋·푸시하면 GitHub Pages에 자동 배포
   - 또는 `raw` 폴더를 압축해 Claude 세션에 올려 주시면 변환·검사·커밋·배포까지 진행합니다.
3. 환자 기기는 다음 실행 때 새 버전을 자동으로 받습니다 (Wi-Fi 권장).

파일이 없는 문장은 앱에서 "모델 음성 준비 중"으로 표시되고 하이라이트 훈련은 그대로 가능합니다. 일부만 먼저 올려도 됩니다 (예: 70 SPM 30개 먼저 → Phase 1 환자부터 사용).
