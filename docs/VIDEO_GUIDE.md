# 기법 설명 영상 제작 가이드 (v1.1)

앱의 "▶ ○○ 설명 영상" 버튼(VideoSlot)에서 재생되는 30–60초 영상 8편입니다. 파일을 `public/video/{key}.mp4` 로 넣으면 버튼이 자동으로 영상을 재생하고, 없으면 "영상 준비 중"을 표시합니다. 오프라인 캐시에 포함되므로 **용량이 중요**합니다.

## 1. 목록과 앱 내 위치

| key | 제목 | 길이 | 앱에서 보이는 곳 |
|---|---|---|---|
| `prolonged` | 연장발화 | 45–60초 | 훈련 메뉴, 연장발화 훈련기 하단 |
| `gentle-onset` | 부드러운 시작 | 30–45초 | 훈련 메뉴 |
| `light-contact` | 가벼운 접촉 | 30–45초 | 훈련 메뉴 |
| `probe` | 주간 평가 녹음 방법 | 45–60초 | 녹음 › 주간 평가 선택 시 |
| `sr-nat` | SR·NAT 평가법 | 45–60초 | 녹음 › 기저·보정 선택 시 |
| `thought-record` | 사고 기록 | 45–60초 | 마음 › 사고 기록 하단 |
| `cancellation` | Cancellation | 30–45초 | 말더듬 수정법 › Cancellation |
| `pullout` | Pull-out | 30–45초 | 말더듬 수정법 › Pull-out |

## 2. 기술 사양

| 항목 | 값 | 이유 |
|---|---|---|
| 화면비·해상도 | **9:16, 720×1280** | 앱이 세로 모바일 화면, 카드 폭에 맞춰 표시 |
| 프레임 | 30fps | |
| 비디오 | H.264 (High), CRF 28 전후, 최대 약 900kbps | iOS Safari·Android Chrome 모두 재생 |
| 오디오 | AAC 64kbps 모노 | 내레이션 위주 |
| 컨테이너 | mp4, **faststart** | 탭하자마자 재생 시작 |
| 편당 용량 | **≤ 7MB** (8편 합계 ≤ 55MB) | 앱 전체 목표 < 80MB (모델 음성 약 10MB 포함) |
| 자막 | **한국어 자막 화면에 굽기** | 소리 끄고 보는 환자가 많음 |

Remotion 렌더 후 최종 압축:

```bash
npx remotion render src/index.ts Prolonged out/prolonged-raw.mp4 --codec=h264 --crf=26
ffmpeg -nostdin -i out/prolonged-raw.mp4 -vf scale=720:1280 -c:v libx264 -profile:v high -preset slow \
  -crf 28 -maxrate 900k -bufsize 1800k -pix_fmt yuv420p \
  -c:a aac -b:a 64k -ac 1 -movflags +faststart public/video/prolonged.mp4
ls -lh public/video/   # 편당 7MB 이하 확인
```

Remotion 컴포지션 권장값: `width={720} height={1280} fps={30}`, 길이 `durationInFrames = 초 × 30`.

## 3. 공통 연출 원칙

- 진단·치료 효과 표방 금지. "~하면 낫습니다" 대신 "~하는 연습입니다", "외래에서 배운 방법을 집에서 연습하는 데 도움이 됩니다".
- 시범 발화의 속도는 **모델 음성과 같은 SPM**으로 (연장발화 시범 = 70 SPM). 화면에 앱과 같은 노란 음절 하이라이트를 띄우면 앱과 연결됩니다 (`--hl: #ffd166`, 앱 주색 `#2f6f5e`).
- 실제 환자 얼굴·목소리는 사용하지 않음 (동의를 받은 경우 제외). 원장·언어재활사 또는 일러스트/입 모양 애니메이션.
- 한 영상 = 한 가지 기법. 마지막 장면은 "앱에서 해 보기" 안내로 끝.
- 화면 글자는 한 줄 14자 내외, 최소 48px (720 폭 기준).

## 4. 원고 초안

내레이션은 1초에 약 4음절 기준으로 길이를 맞췄습니다. 원장님 말투로 다듬어 주세요.

### 4.1 `prolonged` — 연장발화 (약 55초)

| 시간 | 화면 | 내레이션 / 자막 |
|---|---|---|
| 0–6초 | 제목 "연장발화" | 연장발화는 소리를 부드럽게 늘이고, 끊지 않고 이어서 말하는 방법입니다. |
| 6–18초 | 문장 "아침에 물을 마셔요." 음절 하이라이트가 70 SPM으로 진행, 시범 음성 | 처음에는 아주 천천히, 1분에 70음절 정도로 연습합니다. 들어 보세요. (시범: 아—침—에—물—을—마—셔—요) |
| 18–34초 | 세 가지 큐 카드가 차례로 | 세 가지만 기억하세요. 첫소리는 숨을 살짝 내쉬며 부드럽게. 입술과 혀는 가볍게 닿게. 그리고 음절 사이를 끊지 않고 소리를 계속 이어요. |
| 34–46초 | 속도 단계 70 → 120 → 150 → 180 막대 | 익숙해지면 외래에서 속도를 조금씩 올립니다. 목표는 자연스럽게 들리면서도 편하게 말하는 것입니다. |
| 46–55초 | 앱 화면: 모델 듣기 → 따라 하기 → 녹음 비교 | 앱에서 모델 음성을 듣고, 하이라이트를 따라 말한 뒤, 내 목소리와 비교해 보세요. |

### 4.2 `gentle-onset` — 부드러운 시작 (약 40초)

| 시간 | 화면 | 내레이션 / 자막 |
|---|---|---|
| 0–8초 | 제목 | 말이 막히는 순간은 첫소리에서 가장 많이 생깁니다. |
| 8–22초 | 목·성대 단순 일러스트: 세게 닫힘(빨강) vs 살짝 열림(초록) | 첫소리를 힘주어 터뜨리지 말고, 숨을 살짝 먼저 내보내며 작은 소리로 시작해 보세요. |
| 22–34초 | "오늘" "안녕하세요" 시범: 강한 시작 ✗ → 부드러운 시작 ✓ | (시범) 오—늘. 안—녕하세요. 소리가 0에서 천천히 커진다고 생각하면 쉽습니다. |
| 34–40초 | 앱 큐 카드 | 훈련기 위쪽 "부드러운 시작" 카드를 떠올리며 연습하세요. |

### 4.3 `light-contact` — 가벼운 접촉 (약 40초)

| 시간 | 화면 | 내레이션 / 자막 |
|---|---|---|
| 0–8초 | 제목, 입술·혀 측면 일러스트 | ㅂ, ㄷ, ㄱ 같은 소리는 입술이나 혀가 닿았다 떨어지며 납니다. |
| 8–22초 | 세게 붙음(✗) vs 살짝 스침(✓) 애니메이션 | 이때 꽉 누르면 막히기 쉽습니다. 깃털이 스치듯 살짝만 닿게 해 보세요. |
| 22–34초 | "바다" "도서관" "가방" 시범 | (시범) 바다. 도서관. 가방. 소리가 끊기지 않고 흘러갑니다. |
| 34–40초 | 앱 화면 | 연장발화 훈련 문장으로 매일 조금씩 연습하세요. |

### 4.4 `probe` — 주간 평가 녹음 방법 (약 50초)

| 시간 | 화면 | 내레이션 / 자막 |
|---|---|---|
| 0–8초 | 제목, 달력에 매주 체크 | 주간 평가 녹음은 일주일에 한 번, 내 말하기를 확인하는 녹음입니다. |
| 8–20초 | 앱: 녹음 › 주간 평가, 이번 주 주제 | 앱이 주제를 알려 줍니다. 누군가에게 이야기하듯 2분 동안 말해 주세요. |
| 20–32초 | "기법 의식하지 않기" "평소처럼" 자막 | 훈련처럼 천천히 말하려 애쓰지 말고, 평소대로 말하는 것이 중요합니다. 단계 승급은 이 녹음으로 판단합니다. |
| 32–44초 | 앱: 재생하며 [음절] [말더듬] 탭 | 녹음을 들으며 음절마다 버튼을 누르고, 더듬은 음절은 말더듬 버튼만 누릅니다. 그러면 %SS가 자동으로 계산됩니다. |
| 44–50초 | 홈 "이번 주 평가 녹음 완료" | 매주 비슷한 요일에 하면 변화를 보기 좋습니다. |

### 4.5 `sr-nat` — SR·NAT 평가법 (약 55초)

| 시간 | 화면 | 내레이션 / 자막 |
|---|---|---|
| 0–8초 | 제목 | 내 말하기를 평가하는 두 가지 점수를 알아봅시다. |
| 8–24초 | SR 척도 1–10 막대, 1 "없음" / 10 "극심" | SR은 오늘 말더듬이 얼마나 심했는지입니다. 1은 전혀 없음, 10은 가장 심한 정도입니다. 일일 기록에서는 하루 전체를 떠올리며 매겨 주세요. |
| 24–40초 | NAT 척도 1–9 | NAT는 녹음을 들었을 때 내 말이 얼마나 자연스럽게 들리는지입니다. 1은 아주 자연스러움, 9는 아주 부자연스러움입니다. 연장발화를 쓰면 처음에는 숫자가 높을 수 있어요. |
| 40–55초 | 환자·원장 점수 비교 표 (차이 ≤2 ✓) | 처음 몇 번은 외래에서 원장님과 같은 녹음을 따로 평가해 점수를 맞춰 봅니다. 차이가 2점 이내면 통과입니다. |

### 4.6 `thought-record` — 사고 기록 (약 55초)

| 시간 | 화면 | 내레이션 / 자막 |
|---|---|---|
| 0–10초 | 상황 → 생각 → 불안 화살표 | 같은 상황에서도 어떤 생각이 드느냐에 따라 불안의 크기가 달라집니다. |
| 10–22초 | 예시: 카페 주문 / "막히면 점원이 답답해할 거야" 확신도 80 | 예를 들어 카페에서 주문할 때 "막히면 점원이 답답해할 거야"라는 생각이 들 수 있죠. 얼마나 믿는지 0에서 100으로 적어 봅니다. |
| 22–38초 | 지지 증거 / 반대 증거 두 칸 | 그 생각을 지지하는 증거와 반대되는 증거를 나란히 적어 보세요. 대부분은 끝까지 기다려 주었다는 것도 증거입니다. |
| 38–50초 | 대안적 생각, 확신도 80 → 45 | 그리고 더 균형 잡힌 생각을 만든 뒤 처음 생각을 다시 매겨 봅니다. 조금만 내려가도 의미 있는 변화입니다. |
| 50–55초 | 앱 화면 | 마음 훈련에서 사고 기록을 시작해 보세요. |

### 4.7 `cancellation` (약 40초)

| 시간 | 화면 | 내레이션 / 자막 |
|---|---|---|
| 0–8초 | 제목 | Cancellation은 더듬은 단어를 부드럽게 다시 말해 보는 방법입니다. |
| 8–30초 | 3단계 카드 + 시범: "가-가-가방" → (1.5초 정지, 타이머) → "가아방" | 첫째, 더듬은 단어를 끝까지 말합니다. 둘째, 1–2초 멈추고 몸의 긴장을 알아차립니다. 셋째, 같은 단어를 연장발화로 부드럽게 다시 말합니다. |
| 30–40초 | 앱: 단어 카드 + 정지 타이머 | 앱의 단어 카드와 정지 타이머로 연습해 보세요. |

### 4.8 `pullout` (약 40초)

| 시간 | 화면 | 내레이션 / 자막 |
|---|---|---|
| 0–8초 | 제목 | Pull-out은 막힌 순간에 그 안에서 부드럽게 빠져나오는 방법입니다. |
| 8–30초 | 시범: "바—" (막힘, 긴장 표시 빨강) → 긴장 풀림(초록) → "바아아다" | 막혔을 때 억지로 밀어내지 말고 잠시 머무르세요. 입술과 목의 힘을 천천히 풀고, 소리를 길게 늘이며 빠져나와 말을 이어 갑니다. |
| 30–40초 | 앱: 시범 듣기 → 녹음 → 비교 | 앱에서 시범을 듣고 내 녹음과 비교해 보세요. |

## 5. 반영

1. 8편을 `public/video/{key}.mp4` 로 저장 → 편당 용량 확인
2. 언어재활사 검수 후 `content/REVIEW.md` 에 기록 (표에 "기법 설명 영상" 행 추가)
3. 커밋·푸시하면 자동 배포. 또는 mp4를 Claude 세션에 올려 주시면 압축·검사·배포까지 진행합니다.
